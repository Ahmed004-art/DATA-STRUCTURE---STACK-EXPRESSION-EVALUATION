## 1. Description

This program reads mathematical expressions from a text file (`input.txt`), evaluates each expression using a **stack-based approach**, and writes the results to `output.txt`, keeping the same layout (and separators) as the input file.

Two stacks are used for evaluation:

| Stack | Holds |
|-------|-------|
| Operand stack | numbers waiting to be used |
| Operator stack | `+ - * /` and `(` waiting to be applied |

A custom `Stack` class (with `push`, `pop` and `peek`) is implemented from scratch on top of a Python list.

## 3. Requirements

- Python 3.8 or later
- No external libraries are required (only the standard library `os` and `sys`).

## 4. How to Run

1. Place `main.py` and `input.txt` in the same folder.
2. Open a terminal in that folder.
3. Run:

   ```bash
   python main.py
   ```

   (On some systems use `python3 main.py`.)
4. The program prints a table of expressions and results to the console and creates/overwrites `output.txt` in the same folder.

## 5. Input File Structure (`input.txt`)

- One mathematical expression per line.
- Expressions are separated by a line containing only dashes, e.g. `-----`.
- Spaces inside an expression are optional.

Example:

```
3 + 5 * 2
-----
(8 / 4) + 7 * 2
-----
10 - (2 + 3) * 4
```

## 6. Output File Structure (`output.txt`)

- One result per line, in the same order as the input.
- The same separator lines as the input are kept between results.

Output for the example above:

```
13
-----
16
-----
-10
```

## 7. Supported Features

- Operators: `+`, `-`, `*`, `/`
- Parentheses, including nested parentheses
- Operator precedence (`*` and `/` before `+` and `-`)
- Left-to-right evaluation for operators of equal precedence (`100 / 4 / 5 = 5`)
- Decimal numbers (e.g. `2.5 * 4`)
- Unary minus/plus at the start of an expression or after `(` or another operator (e.g. `-5 + 12 / 3`)

## 8. Assumptions and Limitations

- Whole-number results are written without a decimal point (`13`, not `13.0`); other results are rounded to 4 decimal places (`7 / 2 = 3.5`).
- Division is true division (`7 / 2 = 3.5`), not integer division.
- Invalid expressions do not crash the program. The result line contains an error message instead, for example:
  - `Error: division by zero`
  - `Error: mismatched parentheses`
  - `Error: malformed expression`
  - `Error: invalid character 'x'`
- Blank lines in the input are ignored.
- A separator is any line made only of three or more `-` characters; it is copied to the output unchanged.
- Only the four basic operators are supported (no exponent, modulus or functions).
- **Note on the brief's sample:** the assignment sheet shows `17` as the result of `(8 / 4) + 7 * 2`. The mathematically correct value is `2 + 14 = 16`, which is what this program outputs.

## 9. Program Structure

| Function / Class | Role |
|------------------|------|
| `Stack` | `push`, `pop`, `peek`, `is_empty`, `size` |
| `tokenize()` | Splits an expression into numbers, operators and parentheses; handles unary signs |
| `apply_operator()` | Pops one operator and two operands, computes, pushes the result |
| `evaluate_expression()` | Main stack algorithm with precedence and parentheses |
| `process_file()` | Reads `input.txt`, evaluates each expression, writes `output.txt` |
| `main()` | Entry point: runs the program and prints a console summary |
